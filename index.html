Frequently Asked Questions

How does the bug detection engine work?

CodeGuard AI uses client-side AST structural parsing and browser-based sandboxed evaluation combined with rule-based security audits. You can also configure a custom Gemini API key for dynamic generative fixes.

Does my code leave my browser?

By default, all syntax checking and bug audits run 100% locally in your browser. If you supply a custom API key, requests are sent securely directly to the AI service.

AI Core Settings
